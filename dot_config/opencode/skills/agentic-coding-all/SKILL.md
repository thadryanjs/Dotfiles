# agentic-coding-all

Load all agentic-workflow and coding skills into context.

**Do not search or explore.** Use this exact sequence:
1. `ls ~/.config/opencode/skills/`
2. Immediately `read` the `SKILL.md` of every directory starting with `agentic-workflow-` or `code-`.

Ensure full context of the core workflow, logging, review, code-review, maintenance, comprehension, and formatting rules before proceeding.
