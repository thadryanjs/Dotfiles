# Delegation

- Use `explore` for locating files, tracing code, and "where/how" questions.
- Use `general` for self-contained multi-step work that would flood context.
- Delegate when work is separable; keep small edits and tight iteration primary.
- Run independent tasks in parallel; otherwise run foreground.
- Every brief: goal, relevant paths, constraints, done criteria.
- Use background only when independent and I can keep working without it.
- Never delegate from within a subagent.
